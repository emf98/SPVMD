## In this folder: 

* `EMCWF_Retrieval_v1` and `EMCWF_Retrieval_v2.ipyn` are example files for pulling ECMWF S2S reforecast datasets. These files may need updating to properly call data as the API requests may have changed.

* `fitEllipse2_new.py` contains function statements used in calculating the reforecast ellipses. 

* `S2SEllipse_Test.ipynb` provides an example calculation of reforecast ellipses.
